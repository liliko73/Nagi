# Nagi
RUNTEQ卒業制作アプリ

## 1. サービス概要

- このサービスはどんなサービスか
育児中で多くのタスクを抱えてつい頑張ってしんどくなってしまう人の「やらない」を決めて気持ちの安定をサポートするアプリ

- 誰の、どんな課題を、どう解決するか
「育児中で多くのタスクを抱えている人」
の
「完璧にこなそうとするあまりいっぱいいっぱいになって気持ちが不安定になってしまう状態」
を
「「今日やらないこと」を決めることで重要なタスクに集中できる環境を作り、気持ちを安定させるアプリ」

---

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

- いつ
今

- どんな状況で
子供が保育園に通い始める、家を建てて引越し直後、転職のためのプログラミング学習、夫の激務による子育てワンオペ状態が続いているなど、タスクが山積みの状況

- どんな気持ちになったか
・タスクは忘れないようにリストにしておきたいけど、終わっていないタスクを見ると数の多さに絶望する
・いくら時間があっても時間が足りない
・予定通りに進まないとイライラする
・自分で設定したリマインドにすら、通知を見て重たい気持ちになる

- 具体的なエピソード
・子供が保育園に通い始めで頻繁に体調を崩しがち、自分も体調を崩しがちになる、家を建てて引越し直後の家の整理や手続き、転職のためのプログラミング学習をしている、夫の部署でチーム編成が変わって激務になり子育てがワンオペの状態。
・環境の変化や子供の成長に合わせて、日々やること、考えることが多すぎて毎日目が回るような忙しさ
・自分ばっかりやっている気になっていた
・引越しが落ち着いたくらいのタイミングで、本来やるべきことをやるためには時間の使い方を変えないといけないなと思った。
・嫌でもタスクはやらない限り減らないから、どうすれば自分の心も守りながら最低限生活を回せるか考えた。
・思い切って「やらない」ことを意識してみた。
・「今日もできなかった」という思いが、より気持ちを疲弊させていた。
・いつまで経っても終わりが見えなくて、自分の時間が持てなくてそれも辛かった。
・今までは数分で終わることなら先にやってしまっていたけど、それが積み重なって、結局やろうと思っていたことが後回しになっていた。
・多少部屋は荒れるけど、意外とやらなくても生活は回ることに気がついた。
・やることで「これで生活が回る」と安心していた、思い込んでいた面もあるけど、「やらない」勇気を持つことで時間が生まれた。
・時間ができた結果、生活に少し余白が生まれて、気持ちが軽くなる、活力が戻るのを感じた。

---

### 2-2. なぜそれが「気になった」のか

- 自分の性格
・完璧主義
・自分の心身の限界に気づきにくい
・整理整頓が好き（タスクは頭の外に出して整理する）
・効率的に進めるにはどうすればいいかを常に考えてしまう
・今日やるべきことが明確にわかっていれば集中できる
・終わったことよりも終わってないことに目がいく
・常に頭の片隅にタスクを忘れないように置いておくと気になって仕方がない
・ある程度自分の時間がないとかなりストレスが溜まる

- 過去の経験
・今の状況ほどやることに溢れたことは今までないけど、できることは今やってしまおう、効率的に動くにはどう動けばいいかを常に考えてしまう。
・自分ができることは完璧にこなそうとしてしまいがち
・できていないことがあると責められてきたから
・期限に間に合わなくて人に迷惑をかけてはいけないと言われてきたから
・自分で解決できない状況になってから人を頼るように言われてきたから
・自分が頑張ることで解決できることは自分一人でやらないとと思ってきたから

- 大切にしている価値観
・自分の心を守るのが最優先
・自分が笑顔なら家族も笑顔
・効率が全てではない（最近気づいた）

## 10. 技術スタック（手段としての技術）

### 10-1. 使用予定の技術

- フレームワーク：Ruby on Rails
- DB：PostgreSQL
- デプロイ先：Render
- 使用予定ライブラリ：
・Devise（認証機能）
・Ransack（検索機能）
・Turbo / Stimulus（画面更新）
・Kaminari（ページネーション）
・Simple Calendar（カレンダー表示）


---

### 10-2. 技術選定の理由

- なぜこの技術を使うのか
Ruby on RailsはRUNTEQで学習しているため。
新しい技術のキャッチアップに時間を使うよりも、アプリの体験設計や機能改善に時間を使いたいため、学習済みの技術を選択した。

- 今回チャレンジしたい点
・ユーザーごとのタスク管理機能の実装
・タスクの表示切り替え機能
・「今日やる」「全タスク」の分類機能
・Turboを利用した快適な操作体験の実装
・ユーザーが迷わず操作できるUI設計

- 不安な点
・技術のキャッチアップ不足
→単純に初めてのことなので漠然とした不安がある
・既存アプリとの差別化
→機能数ではなく、「今日やること」「今日やらないこと」を決めるという体験価値を重視しながら開発を進めたい。また、開発期間が限られているため、本リリースで予定している機能については優先順位を付けながら実装していきたい。
